! NLN Mirror

Расширение для зеркалирования видео и оконного режима Picture-in-Picture (PiP).

!! Возможности

✅ Manifest V3  
✅ Разделение логики на content.js, background.js и popup.js  
✅ Работа с видео и Shadow DOM  
✅ Обычное зеркалирование видео без перекодирования  
✅ Picture-in-Picture (PiP)  
✅ Обработка различных состояний видео  
✅ Защита от повторной инициализации content.js  
✅ Иконки разных размеров  
✅ Service Worker запускается Chrome по необходимости

!! Установка

1. Скачайте ZIP-архив с расширением.
2. Распакуйте архив в любое удобное место на ПК.
3. Откройте страницу расширений в браузере:
   `chrome://extensions/`
4. Включите **«Режим разработчика»**.
5. Нажмите **«Загрузить распакованное расширение»**.
6. Выберите папку, в которую был распакован архив.
7. Выбирайте именно папку расширения, а не отдельные файлы.

⚠️ После установки не удаляйте распакованную папку с ПК — браузер загружает расширение непосредственно из неё.
